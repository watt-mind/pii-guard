# Meta-only OCR: Muse Spark Open reads the text in images (2026-11-02)

LAB-1796, after the LAB-1794 spike. The hackathon allows only Meta models at runtime, and
Tesseract, which read the text in every image, is not one. The default OCR engine is now
**Muse Spark Open** on Baseten (`PII_GUARD_OCR_ENGINE=muse`,
[ADR 0016](../decisions/0016-meta-only-ocr.md)). Tesseract is one setting away
(`PII_GUARD_OCR_ENGINE=tesseract`) and no longer in the Docker images unless built with
`PII_GUARD_TESSERACT=true`. The unmasked image goes to the OCR endpoint, so the local-only
profile accepts Muse only on a self-hosted URL.

On the 24 fictional specimen-style documents, SAM stubbed so only OCR differs, text detector
`rules` + captions ([Muse](../../eval/results/visual/fictional-ocr-muse.md),
[Tesseract](../../eval/results/visual/fictional-ocr-tesseract.md)):

| OCR | Text regions fully covered (cov ≥ 0.9) | MRZ zones | Over-masking | Per image |
| -- | --: | --: | --: | --: |
| Tesseract `hun+eng` | 85.5 % | 6/6 | 0.5 % | about 1 s, on the device |
| **Muse Spark Open, lines + 2 %** | **84.5 %** | 5/6 | 6.7 % | 8.2 s p50, 16.8 s p95 |

- **Lines, not words.** Each line Muse returns is one OCR unit, so a detected value masks its
  whole line: masks are coarser, over-masking rises.
- **Pad the findings, not the lines.** The first build grew every line box by 2 % of the width,
  as the spike scored it. The caption detector then stopped finding values under their captions
  (padded boxes overlap, so "JANE" no longer reads as the line below "Given names"): 43.6 %.
  Keeping the model's boxes for the layout and growing only the masked regions gave 84.5 %.
- **Refusals fail closed.** A reply without JSON is retried once; a second one refuses the
  image (ADR 0006). None of the 24 failed in the recorded run; the spike saw 1 in 24.
- **Cost.** Two live runs of 24 images on Baseten, a few cents of the sponsored Baseten credit.
  The words are recorded in `eval/fixtures/visual/ocr/muse.json`, so the eval replays offline.
