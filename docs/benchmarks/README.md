# Benchmark images

Generated by `pii-guard eval report` from the run records in
[`eval/results/runs/`](../../eval/results/runs/) and the `share` section of
[`config.json`](config.json); never edit them by hand. `pii-guard eval report --check` fails in
CI when one is stale. The numbers behind them, with every other set and system:
[docs/benchmarks.md](../benchmarks.md).

Each image comes in three sizes and two themes, as SVG and PNG:

| Size | File name | Use it for |
|---|---|---|
| 1600×900 | `<name>.png`, `<name>-dark.png` | the README, docs, slides |
| 1200×630 | `<name>-1200x630.png`, `<name>-1200x630-dark.png` | link cards: Open Graph, X, Discord, Slack |
| 1080×1080 | `<name>-1080x1080.png`, `<name>-1080x1080-dark.png` | square posts |

| Image | `<name>` | What it shows |
|---|---|---|
| [Stat card](results-card-1200x630-dark.png) | `results-card` | The headline leak rate, three comparison tools, the claim and the repository URL: it reads with no context |
| [Leak vs over-masking](leak-vs-overmasking.png) | `leak-vs-overmasking` | One point per system on the agent-traffic set; lower-left is better |
| [Every set](results-by-set.png) | `results-by-set` | Leak and over-masking on each fixture set, as grouped bars |
| [Open NER models](open-ner-models.png) | `open-ner-models` | Open PII NER models behind the same rules, head to head |

The PNGs are rasterized without a browser by resvg (`resvg-py`, pinned in the `report`
dependency group) with the [Inter](fonts/OFL.txt) files in [`fonts/`](fonts/) (SIL Open Font
License 1.1; subset to Latin and static weights). Each PNG carries a `pii-guard-source` text
chunk naming the SVG, fonts and renderer it was drawn from; that stamp is what `--check`
compares.
