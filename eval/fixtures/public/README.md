# Public benchmark samples

Fixture files here come from public datasets, not from pii-guard's generator. They are
converted to the [fixture format](../../../src/pii_guard/eval/fixtures.py) and kept small.
They are not part of `eval/fixtures/` runs by default; pass them with `--fixtures`.

The dataset is synthetic ("synthetic PII only, no real personal data is included", per its
card), machine-generated by its authors. Only the open OpenPII component is used: the other
Ai4Privacy datasets (the 400k/300k releases, the commercial PII-Masking-2M components) have
licences that don't allow this.

Rebuild (streams about 920 MB once, verifies the SHA-256, keeps only the sample):

```bash
uv run python -m pii_guard.eval.public.ai4privacy fetch            # writes the files here
uv run python -m pii_guard.eval.public.ai4privacy fetch --check    # fails if the sample differs
```

Label mapping, the merge rule and the caveats (machine-generated Hungarian, LLM Guard
contamination) are in [docs/evaluation.md](../../../docs/evaluation.md#public-benchmark-ai4privacy-openpii-1m).
