- Do not include titles ("Mr", "Mrs", "Ms", "Dr") or a possessive "'s" in a name: for "Dr Jane
  Doe's", report "Jane Doe". Always report the name after a title: for "Mr Smith" or "Ms
  Doe", report "Smith" or "Doe".
- A surname or given name on its own is a separate surface form. List it too, even when the
  full name is already listed: for "Jane Doe ... Dear Ms Doe", report both "Jane Doe" and
  "Doe".
- Addresses can be written in prose ("the flat above the bakery at 12 Elm Street"): report
  the address part ("12 Elm Street"). Postcodes ("SW1A 1AA", "90210") are part of an address.
- National insurance numbers, social security numbers, passport and driving licence numbers
  are ID_DOCUMENT.
- Do not report generic roles ("the seller", "the tenant").
