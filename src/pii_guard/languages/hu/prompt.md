- Hungarian words take suffixes, and the stem can change spelling before them
  ("Zsuzsanna" -> "Zsuzsannának", "Kovács Anna" -> "Kovács Annával"). List the base form
  and, separately, every inflected surface form exactly as written in the text, so that each
  one can be found verbatim.
- Names are written family name first ("Teszt Elek"); married names can end in "-né"
  ("Kovácsné Próba Zsuzsanna"). Report the whole name.
- Do not report generic roles ("az eladó", "a vevő", "a bérlő").
